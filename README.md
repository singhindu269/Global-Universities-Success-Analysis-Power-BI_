# Global Universities Success Analysis – Power BI

## 📊 Project Overview

The **Global Universities Success Analysis** project is an interactive Power BI dashboard designed to analyze and visualize university performance across different countries and key success indicators. The project transforms raw university data into meaningful insights using data cleaning, transformation, modeling, DAX calculations, and interactive visualizations.

The dashboard provides a comprehensive view of university rankings and performance, allowing users to explore trends and compare institutions based on various academic and institutional metrics.

## 🎯 Project Objectives

* Analyze global university performance and rankings.
* Compare universities across different countries.
* Identify countries with strong university representation.
* Analyze key academic and institutional performance indicators.
* Identify trends and patterns in university success.
* Present complex data through an easy-to-understand interactive dashboard.

## 📈 Dashboard Features

The Power BI dashboard includes interactive **KPI cards, charts, tables, maps, slicers, and filters** to provide a user-friendly analytical experience.

Key analysis areas include:

* University ranking and performance analysis
* Country-wise university comparison
* University-level performance analysis
* Academic and research indicators
* Comparative performance trends
* Interactive filtering by country and university
* Identification of high-performing institutions

## 🛠️ Tools & Technologies

* **Power BI** – Dashboard development and visualization
* **Power Query** – Data cleaning and transformation
* **DAX** – Measures and calculated analysis
* **Data Modeling** – Structuring data for efficient reporting
* **Data Visualization** – Presenting insights through interactive charts

## 🔍 Key Insights

The dashboard helps users understand how universities perform globally and how performance varies across countries and institutions. It enables quick identification of high-performing universities, comparison of institutional metrics, and exploration of patterns within the dataset.

## 💡 Skills Demonstrated

This project demonstrates practical skills in **data analysis, data cleaning, Power BI dashboard development, DAX, data modeling, visualization, KPI creation, and business-oriented storytelling**.

The project showcases how Power BI can be used to convert complex global education data into an interactive analytical solution that supports data-driven exploration and decision-making.
